# 考题一 · 报表用例（Test / Use Cases 设计）

> 本文档定义 `report.xlsx` 生成脚本的**用例基线**，是 `tests/` 目录与人工验收的直接依据。
> 与 `01-需求澄清清单.md` 的验收标准（AC-01 ~ AC-09）逐条对应。
> 版本：v1.0

---

## 0. 用例分层

| 层 | 名称 | 目的 | 数据来源 |
|---|---|---|---|
| L1 | 主流程用例 (Happy Path) | 证明正常输入能得到正确报表 | `fixtures/normal.csv`（内联构造，含已知期望值） |
| L2 | 边界用例 (Boundary) | 证明临界值行为正确 | 内联构造 |
| L3 | 异常用例 (Error) | 证明异常输入不崩溃、有可读提示 | 临时目录动态构造 |
| L4 | 不变量用例 (Invariant) | 证明结果确定性/守恒性/只读性 | 内联构造 + 文件哈希 |

## 1. 主流程用例（L1）

### TC-01 正常四表生成（对应 AC-01、AC-02）

- **前置**：构造 3 行合法销售数据
- **输入**：

| 日期 | 销售员 | 产品 | 数量 | 单价 | 地区 |
|---|---|---|---|---|---|
| 2024-01-05 | 张三 | A | 2 | 10.00 | 华东 |
| 2024-01-20 | 张三 | B | 1 | 30.00 | 华北 |
| 2024-02-03 | 李四 | C | 4 | 25.00 | 华东 |

- **操作**：`generate_report(input, output)`
- **期望**：
  - `明细清洗后`：3 行，`销售额` 列 = `20.00, 30.00, 100.00`
  - `按销售员`：张三 = 50.00（2 行），李四 = 100.00（1 行）
  - `按地区`：华东 = 120.00（2 行），华北 = 30.00（1 行）
  - `总览`：总销售额 150.00，2024-01 月度 = 50.00，2024-02 月度 = 100.00
  - 工作表名与顺序 = `["明细清洗后", "按销售员", "按地区", "总览"]`
  - 退出码 0

### TC-02 销售额计算口径 = 逐行 数量×单价（对应 AC-04）

- **前置**：构造数据使得"逐行乘后汇总" ≠ "汇总数量 × 汇总单价"：
  - 同一销售员两行：`3 × 10.00 = 30.00` 与 `2 × 20.00 = 40.00`
  - 错误算法（3+2=5 数量 × 平均单价）会得到不同结果
- **期望**：该销售员销售额 = **70.00**（而非任何加权错误值）

### TC-03 销售额占比之和 = 100%（对应 AC-04）

- **前置**：TC-01 数据
- **期望**：`按销售员` 表 `销售额占比` 合计 = 100.00（±0.01 容差）；`按地区` 同理

### TC-04 排序确定性（对应 AC-04）

- **前置**：构造销售额**并列**的两个销售员（如 `张三 100.00` / `李四 100.00`）
- **期望**：按销售额降序，并列时**按名称升序**（字符串序），多次运行顺序稳定

## 2. 边界用例（L2）

### TC-05 全字段重复行只保留一条（对应 AC-03）

- **输入**：TC-01 第 1 行**完全重复 3 次**（共 5 行）
- **期望**：
  - `明细清洗后` = 3 行（重复的 2 行被剔除）
  - `剔除统计 · 全字段重复` = **2**
  - 张三销售额仍为 50.00（不因重复而翻倍）

### TC-06 数量 = 0 与 数量 = -5 均被剔除（对应 AC-03）

- **输入**：1 行合法 + 1 行 `数量=0` + 1 行 `数量=-5`
- **期望**：`明细清洗后` = 1 行；`剔除统计 · 数量<=0` = **2**

### TC-07 边界：数量 = 1、单价 = 0.01（最小合法正值）

- **输入**：`数量=1, 单价=0.01`
- **期望**：**保留**该行（`>0` 是开区间，1 与 0.01 合法）；销售额 = 0.01

### TC-08 仅 1 行有效数据

- **输入**：单个合法行
- **期望**：正常生成四表；`按销售员`/`按地区` 各 1 行；占比 = 100.00

### TC-09 日期解析多样性与月度分组（对应 AC-04）

- **输入**：同一月份的三种写法 `2024-03-01`、`2024/3/15`、`2024-03-31`（其他列合法）
- **期望**：全部解析成功；`总览` 中 `2024-03` 月度总额 = 三者销售额之和（**合并为一个月**，不得拆成多行）

### TC-10 跨年边界日期

- **输入**：`2023-12-31` 与 `2024-01-01`
- **期望**：`总览` 中生成 `2023-12` 与 `2024-01` **两行**月度记录，不合并

### TC-11 关键字段"空白字符串"视为缺失（对应 AC-03）

- **输入**：`销售员 = "   "`（纯空格）的一行
- **期望**：判定为缺失 → 剔除；计入 `剔除统计 · 关键字段缺失`

### TC-12 列名含首尾空白自动归一化（对应 C-05）

- **输入**：表头为 `" 日期 ", "销售员", "产品", "数量", "单价", " 地区 "`
- **期望**：正常识别为合法表头，不报"缺少列"

### TC-13 产品列缺失（非关键字段）（对应 D-01、D-02）

- **输入**：`产品` 为空的一行（其他关键字段合法）
- **期望**：该行**保留**，`产品` 填 `未填写`；销售额正常计入

### TC-14 非法数值文本（对应 C-11 防御）

- **输入**：`数量 = "待定"` 的一行
- **期望**：该行被剔除，计入 `异常数值/日期`；**不抛异常**、不崩溃

### TC-15 非法日期（对应 R-07）

- **输入**：`日期 = "2024-13-45"` 的一行
- **期望**：该行被剔除，计入 `异常数值/日期`

### TC-16 Excel 序列日期（整数）被正确解析（对应 R-07）

- **输入**：`日期 = 45292`（Excel 序列号，= 2024-01-01）
- **期望**：解析为 2024-01-01，落入 `2024-01` 月度分组

## 3. 异常用例（L3）— 考题要求"至少 2 个边界/异常用例"，此处覆盖 6 个

| 用例 | 场景 | 期望行为 | 退出码 |
|---|---|---|---|
| **TC-17** | 输入文件**不存在** | `InputFileNotFoundError`，消息含实际查找路径 | 2 |
| **TC-18** | 文件存在但**工作表完全为空**（0 行） | `EmptyDataError`，提示"文件中没有任何数据行" | 3 |
| **TC-19** | 有表头但**全部行都被清洗剔除**（无有效数据） | `NoValidDataError`，提示剔除原因统计；**不生成** report.xlsx | 3 |
| **TC-20** | **缺少必需列**（去掉 `单价`） | `MissingColumnsError`，消息**列出缺失列名** + 实际表头 | 4 |
| **TC-21** | 空文件（0 字节 / 非 Excel 内容） | `InvalidWorkbookError`，提示"不是有效的 Excel 文件" | 5 |
| **TC-22** | 输出路径与输入路径**相同**（防覆写原文件） | `SamePathError`，拒绝执行 | 6 |

### TC-23 总销售额为 0 时不除零崩溃（边界）

- **输入**：所有行 `单价 = 0` → 全部被剔 → 实际属于 TC-19
- **变体**：构造有效数据但销售额合计恰为 0 的组合不可能（数量>0 且单价>0 ⇒ 销售额>0），故本用例改用**直接调用统计函数**传入空分组，断言 `占比` 返回 `0.00` 而非 `ZeroDivisionError`

## 4. 不变量用例（L4）

### TC-24 原始文件只读（对应 AC-06、R-01）

- **操作**：记录输入文件 SHA256 → 运行脚本 → 再次记录
- **期望**：哈希**完全一致**；且输出的 `明细清洗后` 行数 ≤ 原始行数

### TC-25 幂等性 / 可复现（对应 AC-07、C-08）

- **操作**：同一输入连续运行 2 次，输出到两个不同路径
- **期望**：两个输出文件的**内容哈希一致**（无时间戳、无随机数、无 `id()`）

### TC-26 清洗守恒：原始行数 = 清洗后行数 + 各剔除原因之和（对应 AC-03、D-02）

- **操作**：对任意含多种脏数据的数据集运行
- **期望**：`len(raw) == len(cleaned) + dropped_missing + dropped_nonpositive + dropped_duplicate + dropped_invalid`
- **意义**：这条不变量能**一次性抓住**"某行被静默吞掉"的严重 bug

### TC-27 明细合计 = 汇总表合计 = 总览总额（三方对账）

- **期望**：`明细.销售额.sum() == 按销售员.销售额.sum() == 按地区.销售额.sum() == 总览.总销售额`

### TC-28 输出目录不存在时自动创建（对应 C-06）

- **操作**：`--output` 指向 3 层不存在的新目录
- **期望**：自动创建并成功写出

### TC-29 输出文件已存在时被覆盖（对应 C-07）

- **操作**：先放一个旧 `report.xlsx`，再运行
- **期望**：被新报表替换，工作表为新的 4 张（无旧表残留）
